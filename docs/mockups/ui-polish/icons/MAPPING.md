# Phosphor icon mapping

Phosphor Icons 2.1 (`@phosphor-icons/core` 2.1.1) · MIT (`phosphor/LICENSE`) · https://phosphoricons.com

Weights: **Regular** = default · **Fill** = active nav item, play/pause, status-chip icons (not `check`) · **Duotone** = inside coloured icon tiles. Files: `phosphor/<weight>/<name>.svg`. Generate Kotlin with `python3 phosphor_to_kotlin.py <package> [keys…] > AfIcons.kt`.
