# Decisions (ADR-lite). Do not reopen without a new entry.

D-01 KMP + Compose Multiplatform over Flutter — owner's Kotlin expertise, YFT code reuse.
D-02 Project-as-folder with immutable content-hash artifacts; SQLite only as index.
D-03 Stale detection via recorded inputs, not status cascades.
D-04 Video generation is manual via Google Flow. No automation of Google UIs — ToS/account risk and brittleness.
D-05 Gemini API free tier (AI Studio key) for text/image/TTS. AI Pro subscription is NOT an API credential; it only applies to Flow/AI Studio UI.
D-06 No backend, accounts, billing, or custom sync. Syncthing/folder copy is the sync method.
D-07 Desktop video playback: VLCJ first. Fallback if spike S3 fails: ffmpeg-extracted thumbnails + "open externally", playback deferred.
D-08 Android does not render. ffmpeg-kit is retired; Media3 Transformer only for preview concat if ever needed.
D-09 Voice replication is an optional, capability-gated feature. Default narration path is user recording; standard TTS second.
D-10 Model names/quotas/credit costs live in `config/models.json`, never in code.
D-11 Koin for DI (KMP). kotlinx.serialization for all persisted models.
D-12 Burmese text for humans, English for models; separate fields, never auto-translated silently.
D-13 Toolchain pinned as one set in `gradle/libs.versions.toml` only: Kotlin 2.4.21, Compose Multiplatform 1.12.2, AGP 9.3.3, Gradle 9.7.1, kotlinx.serialization 1.12.0, coroutines 1.11.0, Ktor 3.6.1, Koin 4.2.2 (newest set inside Kotlin 2.4.21's tested Gradle/AGP range); shared modules use `com.android.kotlin.multiplatform.library` + `jvm("desktop")`; JVM target 17, minSdk 26, compileSdk 37; no Material3 (custom theme per DESIGN.md); upgrade versions together as a set.
D-14 Reference images: manual handoff by default — copy the ImageDialect prompt, generate in the AI Studio UI or Flow (covered by the AI Pro subscription), import the file as Ref A/B. `GeminiImageProvider` is optional and capability-gated: a probe that returns 429 with `limit: 0` marks it unavailable. Reason: spike S2 — every Gemini image model has zero free-tier API quota, and D-05/D-06 rule out API billing.
D-15 GeminiTextProvider resilience: the model fallback chain is the stage's ordered `candidates` list in `config/models.json` (never in code), applied at every stage call; exponential backoff on 500/503 (and on 429 when `retryDelay` ≤ 60 s); request timeout 120 s per attempt, and every running AI call shows a Cancel button; app-side daily request counter, because the API returns no rate-limit headers. Reason: spike S1 — `gemini-2.5-flash` refused for new keys, `gemini-3.8-flash` mostly 503, and 3.5-flash 503 on about half of calls. (Amended 2026-11-10: timeout 300 s → 120 s + Cancel; chain source = `candidates`.)
D-16 VLC is not bundled. Playback uses a separately installed VLC 3.0.x (64-bit): Settings → "VLC path", auto-detected at `C:\Program Files\VideoLAN\VLC`. If VLC is not found, show an "Install VLC" link (videolan.org) and disable playback; shots show ffmpeg-extracted thumbnails only. Reason: spike S3 — even a trimmed VLC adds ≈95 MB to the installer plus LGPL/GPL plugin licensing; VLCJ JARs (3.7 MB) stay in the app. Closes Q-05.
D-17 Test-only libraries: `kotlinx-coroutines-test` (virtual time for retry/backoff and fake-delay tests) and `ktor-client-mock` (HTTP-free provider tests). Versions come from the D-13 `kotlinx-coroutines` / `ktor` refs; never on a main classpath.
D-18 File access: `:core` owns the small `core.io.FileSystem` port (exists/createDirectories/list/read/writeDurably/atomicMove; `watch` added with the Inbox in 1C-d) with `InMemoryFileSystem` for tests. `:platform` implements `JvmFs` (java.nio: `FileChannel.force` + `ATOMIC_MOVE`) in a source set shared by desktop and Android, which adds the `:platform → :core` edge. Android SAF arrives in phase 3 as another implementation; `:core` does not change. Closes Q-06.
D-19 API key storage on Windows: JNA (`jna` + `jna-platform` 5.17.0, desktop only) for DPAPI `CryptProtectData` (current-user scope); `SecureStorage` keeps the encrypted blob in `~/.autoflow/secrets.bin` (atomic write). Simpler than Credential Manager with the same per-user binding. Other desktop OSes report `Unsupported` (no env-var fallback, AGENTS.md §1), so Real AI mode needs Windows. Android (EncryptedSharedPreferences) in phase 3.
D-20 Amends D-02: the project index is a rebuildable JSON list `~/.autoflow/projects.json` (path, name, mode, ratio, progress, last opened), not SQLite, until project counts need more. No new dependency; losing it loses no data (re-open the folders).
